## **Welcome to Archefot!**

**This is an open-source encryption tool I made**



This tool uses proprietary file formats for security. While technically openable in Notepad, it's unreadable due to the AES-256 encryption.



Let's jump right in. 



To create an ARCHKEY, begin with opening keycreation.vbs. You can keyboard spam, or randomize one, but there cannot be any repeating letters, or numbers, and there cannot be any symbols in the ARCHKEY. To start with the tool, open archefot.vbs. Upon startup, it will ask you for your .archkey file. Then, choose your text file, and import. You will see a randomly generated name on the preview next to the suffix text box, that is normal. Remember ✨security✨. You also have the option to change the suffix, just delete the old text, and replace. Below that is the N.O.P. number. The N.O.P. Number states how many times your archkey code will be applied to the text, "NOP" standing for Number of Passes, or as my dad has taken to call it "The Nope Number" Then Archefot takes that output post-NOP and encrypts it, and turns it into a password protected AES-256-encrypted .arcf file. A randomly generated password will be also be formed underneath the buttons; DO NOT LOSE IT.



To decrypt, open the same .archkey file and unlock, import your .arcf file, enter your password below by pasting, or typing it in manually, and hit decrypt.



Everything will output in \[<script location>/output], so look there for your stuff.



If you use the wrong key, you can't open it

However, if you lose the password, YOU. CANNOT. RECOVER. THE. TEXT.



Good luck, and thanks for using Archefot.
